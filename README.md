# HorizonSync

A simple static landing page for HorizonSync, published with GitHub Pages.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push to the `main` branch, or run the **Deploy to GitHub Pages** workflow from the Actions tab.

The site is served from [`index.html`](index.html). No build step or dependencies are required.
